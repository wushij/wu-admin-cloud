## 1. 执行摘要

### 1.1 总体结论

| 评估维度 | 完成度 | 结论 |
|---------|--------|------|
| **微服务功能完整性** | ~90% | 11 个 JVM 应用可独立部署，RBAC、工单、IM、AI、支付、监控等核心能力齐全 |
| **单体功能迁移** | ~95% | 日常后台功能可替代原单体，前后端已联调打通 |
| **行为一致性** | ~90% | 登录、鉴权、接口安全、IM、工单等与单体行为对齐 |
| **API 路径规范化** | ~70% | 核心域已迁新路径，导出等仍混用旧路径 |
| **架构纯净度** | ~50% | 共库、跨域 JDBC 直查、网关兼容层仍在 |
| **生产级收尾** | ~40% | 缺 MQ、链路追踪、容器编排、真·分库 |

**一句话：**

- 问「微服务能不能用、能不能替代单体？」→ **可以，迁移主体已完成。**
- 问「迁移是否彻底、能否宣告收尾？」→ **还不行**，仍有共库、兼容路由、跨域直查等待清理项。

```text
客户端
  → Nginx（/api 反代）
  → wu-cloud-gateway:8080
      ├─ HeaderCleaningFilter（清洗伪造 X-User-*）
      ├─ InnerApiGuardFilter（/inner/** 外部 403）
      ├─ SaReactorFilter（Sa-Token 登录校验）
      ├─ ApiSecurityFilter（HMAC-SM3 + SM4，DB 动态开关）
      ├─ AuthGlobalFilter（注入 X-User-Id / X-User-Name 等）
      └─ 路由 lb://{service-name}
  → 业务微服务
      └─ UserContextInterceptor（还原线程上下文）
```

### 6.2 接口约定

| 类型 | 路径模式 | 访问方式 |
|------|----------|----------|
| 对外 API | `/api/{域}/**` | 经网关，需鉴权 |
| 内部 API | `/inner/{域}/**` | Feign 直连 `lb://`，网关入站 403 |
| WebSocket | `/ws/**` | 网关 Upgrade 透传至 message 服务 |

### 6.3 一致性策略

当前 **无消息队列**，采用渐进式一致性：

```text
强一致场景：Feign 同步调用 + 本地事务
弱一致场景：Outbox 表 + Quartz 定时补偿（wu-service-infra）
```

Outbox 流程：

1. 业务服务在本地事务提交后，Feign 调用 `RemoteOutboxService.save()` 写入 `infra_outbox`
2. `OutboxCompensateJob` 定时扫描 PENDING 记录，重试调用目标服务
3. 成功标记 DONE，失败递增 retryCount 并延迟 nextRetryTime

### 6.4 BFF 聚合模式（wu-admin）

仪表盘 `DashboardServiceImpl` 采用：

- `CompletableFuture` 并行调用 6+ 个 Remote 服务
- 单路 RPC 超时 800ms，整体等待上限 1200ms
- Redis 分钟级缓存（`dashboard:bff:stats:v1:{userId}`）
- 下游不可用时不拖垮首屏，字段降级为 0 或空

## 7. 安全体系

### 7.1 鉴权链

```text
Gateway SaReactorFilter 校验 Token
  → AuthGlobalFilter 注入 X-User-Id / X-User-Name / X-Dept-Id 等
  → 业务服务 UserContextInterceptor 还原 UserContextHolder
  → @RequiresPermissions 注解鉴权（菜单/按钮级）
```

### 7.2 接口安全（国密）

| 能力 | 实现 | 开关 |
|------|------|------|
| HMAC-SM3 请求签名 | 网关 ApiSecurityFilter | DB `security.sm2SignEnabled` |
| SM4 请求/响应加解密 | 网关 ApiSecurityFilter | DB `security.sm4EncryptEnabled` |
| 时间戳窗口 | 默认 5 分钟 | DB `security.timestampEnabled` |
| Nonce 防重放 | Redis setIfAbsent | DB `security.nonceEnabled` |
| 会话密钥下发 | `/api/auth/session-sign-init` | 按 X-Client-Id 写入 Redis |

### 7.3 内部接口保护

- 网关 `InnerApiGuardFilter` 拦截所有入站 `/inner/**` → 403
- 服务间 Feign 走 `lb://` 直连，不经网关
- 网关 `HeaderCleaningFilter` 防止客户端伪造 `X-User-*`
- **服务侧无 inner 鉴权**：各微服务的 `/inner/**` Controller 不校验 Token；开发环境若直连 9201~9300 端口，inner 接口对外暴露且无鉴权。**生产必须**仅允许集群内网访问，禁止将业务服务端口直接暴露公网

### 7.4 已知安全注意项

| 项 | 现状 | 生产建议 |
|----|------|----------|
| inner 接口 | 服务侧无 Token 校验，外部访问仅靠网关 403 | 业务端口不暴露公网，仅内网 Feign |
| CORS | `allowedOriginPattern("*")` + credentials | 收紧为明确域名 |
| api-security | 默认 `enabled: false` | 按环境灰度开启 |
| 密钥存储 | JDBC/支付/AI 密钥应走环境变量 | 禁止明文进 Git/Nacos 公共库 |
